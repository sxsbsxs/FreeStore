提交一个应用

选择 APK 并填写基本资料。提交后会进入人工审核，审核通过才会公开上架。

上传限制：25 MB

继续后会先下载一个 ZIP 文件副本，再打开 GitHub 投稿页。你需要在 GitHub 页面把该文件作为附件添加并提交。需要登录 GitHub。

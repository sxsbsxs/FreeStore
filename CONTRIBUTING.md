# Contributing

Thanks for helping improve FreeStore.

1. Open an issue before large architectural changes.
2. Keep catalog metadata backward-compatible with schema version 1.
3. Never commit APKs, signing keys, passwords, access tokens, or private data.
4. Run the Android build with `gradle :app:assembleDebug`.
5. Keep the website dependency-free and safe when rendering external catalog data.
6. Add third-party apps only when their developers permit redistribution and the repository is public.

By contributing, you agree that your contributions are provided under the repository's MIT License.
